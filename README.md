# Wisdom Pro feedback

The public tracker for **Wisdom Pro** ([wisdompro.app](https://wisdompro.app)): report bugs, request features and follow what's being fixed. There is no code here.

- **Report a bug:** [New issue → Bug report](../../issues/new?template=bug.yml), or use the form on [wisdompro.app/report-bug](https://wisdompro.app/report-bug) (no GitHub account needed), or **Help › Report a Bug…** in the app.
- **Request a feature:** [New issue → Feature request](../../issues/new?template=feature.yml).
- **Already reported?** Search the [issues](../../issues) first and add a 👍 to the one you also hit.

Everything here is public. Don't post personal details, licence keys or private audio. Security problems: email support@wisdompro.app instead of opening an issue.
